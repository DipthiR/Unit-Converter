# Unit-Converter
🧮 Smart Unit Converter
A simple and user-friendly Unit Converter built with Python and Tkinter. It supports conversions between common units of Length, Weight, and Temperature with a sleek graphical interface and intuitive controls.

## ✨ Features
🔄 Real-time conversion of values between units

📐 Supports Length, Weight, and Temperature categories

🎨 Modern and clean Tkinter GUI

🎯 Dropdowns for category/unit selection

⚠️ Error handling for invalid inputs

🧹 Clear button to reset inputs and outputs

## 🧰 Units Supported
Length
Meter, Kilometer, Centimeter, Millimeter, Mile, Yard, Foot, Inch

Weight
Gram, Kilogram, Milligram, Pound, Ounce

Temperature
Celsius, Fahrenheit, Kelvin

## 🚀 Getting Started
Requirements
Python 3.x

No external libraries required (Tkinter is included with Python)

## 🛠️ How to Run
Clone the repository or download the script.

git clone https://github.com/yourusername/unit-converter-tkinter.git
cd unit-converter-tkinter
Run the script:

python unit_converter_gui.py
That's it! 🎉
